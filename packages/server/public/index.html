Everything you'd expect

Built for security, designed for you

A full vault for logins, passkeys, cards, notes, and keys — with the protections of the best commercial managers.

🔐

Zero-knowledge

Your data is encrypted on your device before it's ever synced. The server stores opaque ciphertext and cannot read a single password.

🔑

Passkeys & FIDO2

Sign in passwordlessly with a device key, or add a hardware security key. Phishing-resistant challenge–response, built in.

📱

Every device

Native apps for macOS, Windows, iOS, and Android, plus a browser extension. Your vault syncs everywhere, instantly.

⚡

Smart autofill

The extension fills logins automatically — but only on the exact matching site, so look-alike phishing domains get nothing.

👆

Biometric unlock

Touch ID on Mac, Windows Hello on PC, Face ID on mobile. Your master password gates access; biometrics make it effortless.

🛡️

Built-in 2FA

Time-based one-time codes with QR enrollment, verified server-side. Plus breach monitoring and weak-password alerts.

The security model

Math, not trust

Only your master password can turn stored ciphertext back into readable data. Here's the chain that protects it.

If someone steals the database — or the laptop file — they get encrypted bytes and nothing else. No master password, no key, no plaintext. Tamper with a single byte and decryption fails loudly.
