# VaultKeep Mobile (iOS / Android)

Flutter client for the zero-knowledge vault. The master password never leaves
the phone: Argon2id runs on-device (pure-Dart, **byte-compatible with
`@vaultkeep/crypto`** — proven against fixtures generated by the node core in
`test/fixtures/`), the server sees only the derived auth verifier, and every
blob is AES-256-GCM in the shared `nonce‖ct‖tag` format, so one vault
decrypts on desktop, web, extension, and mobile.

## Layout

| | |
|---|---|
| `lib/core/vault_crypto.dart` | Dart port of the crypto core (KDF, verifier, GCM blobs) |
| `lib/core/auth_client.dart` | zero-knowledge sign-in/register, `needsDevice` self-enrollment, TOTP |
| `lib/core/local_store.dart` | encrypted-at-rest single-blob store (same opaque-blob model as desktop) |
| `lib/core/vault_app.dart` | unlock/lock/add/update + two-way sync with conflict handling |
| `lib/ui/` | sign-in and vault screens (search, detail, add sheet, generator) |
| `tool/live_check.dart` | interop harness — signs into a real server and round-trips an item |

## Develop

```bash
flutter pub get
flutter test        # 21 tests: node-vector compat, GCM gates, sync conflicts, widgets
flutter analyze
flutter run         # Android emulator reaches the host server at http://10.0.2.2:8787
```

Build for release with the standard `flutter build apk` / `flutter build ios`
(requires the Android/iOS toolchains).

Cross-implementation interop is verified live by `tool/live_check.dart`: a
node-registered account signs in from Dart (same derived verifier), pushes a
Dart-encrypted item, and the node core decrypts the stored ciphertext.
